# Contlib Website

React + Vite project for the Contlib landing page.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

The production build is output to the `dist/` folder — upload that to any
static host (Hostinger, Vercel, Netlify, etc.).

## Edit content

Open `src/ContlibLanding.jsx`. Placeholder content is marked with comments
like `// Dhruvin: edit me` — update:
- `WORK` array — real project names, categories, links
- `STATS` array — real numbers
- Testimonial quote and client name
- Footer email / phone number
